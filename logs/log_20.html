Issue: Line Console Connection Lost

Phenomenon:

A Line Console connection error occurred. The installation of patch 0631 on October 3 to enable the OnMcEid_Etool function is suspected to be the cause.

The issue affected all three lines:

  • VS1-03

  • V1-02

  • V1-03

Action Taken:
Restored the NPI files on the LCU according to the instructions:

  1. Copied and pasted the NPI file from the LCU of line VS2-03.

  2. Turned OFF the Fuji LCU NPI Server.

  3. Opened Version.txt and removed the patch_0631 entry.

  4. Reset the LCU.

Result:
The lines operated normally for one day. However, the same issue occurred again on lines V1-02 and V1-03.

Next Action:
Restore the LCU Windows backup created before patch 0631 was installed to check whether the patch caused the issue.
